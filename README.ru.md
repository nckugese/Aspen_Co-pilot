Это перевод; при расхождениях действует [английская версия](README.md).

**Пусть ИИ-агент проектирует, моделирует и оптимизирует химико-технологические процессы
в вашем собственном Aspen Plus — а вы видите каждый шаг и сохраняете контроль.**

Aspen Co-pilot подключает Aspen Plus к ИИ-агентам, таким как Claude Code и Codex, через
Model Context Protocol (MCP). Вы описываете процесс обычным языком; агент выполняет работу
в Aspen, а вы её проверяете.

Только для Windows. Нужна собственная лицензионная копия Aspen Plus; в состав проекта она
не входит. Разработано NCKU GESE Lab.

## Что он умеет

**Создавать и изменять процессы.** Постройте технологическую схему по описанию — компоненты,
методы расчёта свойств, реакции, единичные операции и потоки, — задавайте и корректируйте
любые параметры, запускайте расчёт и читайте результаты. Доступно большинство функций
Aspen Plus.

**От литературы — к работающей модели.** С помощью инструментов поиска вашего ИИ-клиента
агент может собрать кинетику, рабочие условия и технологические маршруты из статей
и патентов, а затем построить на их основе модель Aspen, которую вы сверите с источниками.

**Выяснять, почему расчёт не сходится.** Он проверяет, чего Aspen ещё не хватает перед
запуском, объясняет неудачные расчёты и предупреждения и исправляет их. Сработавшие
исправления сохраняются на вашем компьютере на будущее.

**Оптимизировать процесс.** Девять алгоритмов в одном инструменте — NSGA-II, NSGA-III, PSO,
DE/GDE3, градиентный (SLSQP), поиск по сетке и три байесовских метода (BO, CBO, AFM-CBO) —
для одно- и многокритериальных задач с ограничениями, а также пинч-анализ и подбор пар
теплообменников для тепловой интеграции.

**Сверяться со справкой, а не гадать.** Справочник по каждому блоку, потоку и настройке
([aspen-mcp/docs](aspen-mcp/docs/aspen.md)), к которому агент обращается, прежде чем
изменить поле.

## Создан для работы вместе с людьми

LLM-агенту, который сам управляет программой, трудно доверять: вы не видите, что он изменил
и зачем, и не можете остановить ошибку до того, как она попадёт в модель. Aspen Co-pilot
устраняет этот разрыв с помощью **Aspen Workbench** — настольного окна рядом с Aspen Plus.

- **Видеть, что делает ИИ.** Технологическая схема, результаты и каждое изменение ИИ вместе
  с его обоснованием обновляются в реальном времени. Отмените любое изменение или вернитесь
  к точке восстановления.
- **Сохранять контроль.** В режиме проверки изменения ИИ ждут вашего одобрения; крупные
  изменения приходят в виде предложений, которые можете запустить только вы.
- **Задавать работу самостоятельно с помощью блочных программ.** Собирайте параметрические
  исследования, расчёты, таблицы, графики и оптимизационные задачи — со своими переменными,
  целями и ограничениями — из блоков перетаскиванием, без кода. ИИ может написать программу,
  которую вы отредактируете, или запустить вашу.
- **Работать вместе.** Щёлкните любой поток или блок и спросите о нём через **Ask AI**.
  В режиме обучения ИИ объясняет технологический принцип, стоящий за каждым изменением.

Интерфейс Workbench доступен на английском и китайском языках (русского нет), и она работает
также без ИИ-клиента (`%USERPROFILE%\.aspen-mcp\aspen-workbench.cmd`: без сети, без токенов).

## Установка

Нужны **Windows**, лицензионный **Aspen Plus** и **[uv](https://docs.astral.sh/uv/)**
(`winget install --id=astral-sh.uv -e`; он устанавливает собственный Python).

**Claude Code:**

```bash
claude plugin marketplace add nckugese/Aspen_Co-pilot
claude plugin install aspen-plus@aspen-mcp
```

**Codex:** `codex plugin marketplace add nckugese/Aspen_Co-pilot`, затем включите **Aspen Plus**
в `/plugins` и разрешите его хуки в `/hooks`.

Затем перезапустите клиент. В первом сеансе он предложит завершить настройку (около 200 МБ:
Python, сервер и библиотеки оптимизации); согласитесь и перезапустите клиент ещё раз.
`/aspen-doctor` проверит результат.

Плагин закреплён за одним релизом, поэтому ничего не изменится, пока вы его не обновите
(`claude plugin update aspen-plus@aspen-mcp`); он сообщит, когда выйдет более новый релиз.

Другие MCP-клиенты (Claude Desktop, Gemini CLI, Codex без плагина), пошаговая инструкция
с проверками и устранение неполадок: **[INSTALL.md](INSTALL.md)** (на английском).

## Конфиденциальность

Всё, что хранит сервер, остаётся на вашем компьютере в `~/.aspen-mcp/`: его журнал, журнал
изменений, точки восстановления (копии ваших моделей) и история ошибок. Ваши модели,
результаты и переписка никуда не отправляются этим проектом. Сетевой доступ используется
только для:

- проверки обновлений плагина, не чаще раза в сутки (`git ls-remote` к этому репозиторию);
- первого вызова `pinch_analysis`, который загружает Python 3.14 и OpenPinch через uv;
- установки и обновления, при которых сервер и его зависимости загружаются через uv.

Что ваш ИИ-клиент отправляет своему провайдеру, определяется самим клиентом.
