# Learned features (inbox)

Features learned by watching a GUI demonstration (the observation-knowledge-extraction skill: snapshot, diff, reproduce, record) land here first, one file per feature, with a line below.

An entry stays here until it is checked live and moved into its folder ([blocks/](../blocks/index.md), [setup/](../setup/setup.md), [streams/](../streams/streams.md), ...; see [aspen.md](../aspen.md)). Then its file and its line are removed.

On a user's machine the skill writes to `<ASPEN_USER_DATA>/learned/` instead; this folder ships with the server and an upgrade replaces it.
